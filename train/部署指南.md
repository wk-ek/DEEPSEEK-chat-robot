# 部署运行指南

> 面向 Ubuntu 24.04。全部命令可直接复制粘贴。

---

## 零、你要上传的文件

```
F:\qq-deepseek-robot\dist\amiya-train-20261023.zip     （约 16 MB）
```

这个包里已经有：训练脚本、训练数据、剧情素材、人格档案。**不需要再传别的东西，也不需要 API key。**

---

## 一、上传

在你自己的电脑（Windows PowerShell）上：

```powershell
scp "F:\qq-deepseek-robot\dist\amiya-train-20261023.zip" root@服务器IP:/workspace/
```

> 端口不是 22 就加 `-P 端口号`，比如 `-P 2222`
> 用户名不是 root 就换掉 `root@`

---

## 二、装系统依赖（只需要一次）

登录服务器：

```bash
ssh root@服务器IP
```

装依赖：

```bash
apt update
apt install -y python3 python3-pip python3-venv git unzip
```

检查 GPU：

```bash
nvidia-smi
```

**必须能看到显卡信息。** 如果提示 command not found：

```bash
apt install -y nvidia-driver-550
reboot
```

重启后再 `nvidia-smi` 确认。

```bash
cd /workspace

cd amiya-train
```

确认结构：

ls

## 五、开始训练

```bash
bash train/run.sh
```

就这一条命令。它会自动：

1. 装 LLaMA-Factory（首次 3–5 分钟）
2. **Stage 1** 智慧层 —— 2045 条，让她认识泰拉世界（20–30 分钟）
3. **Stage 2** 说话层 —— 4824 条，学阿米娅的语气（20–30 分钟）
4. **Stage 3** 同人层 —— 59 条，加一点同人的味道（约 5 分钟）
5. 合并导出两个完整模型（10 分钟）

**总共约 1–1.5 小时。**

### 产出

```
/workspace/output/
├── amiya-official-merged/     纯官方版 ← 推荐主用这个
├── amiya-extra-merged/        官方 + 同人版
├── stage1-wisdom/             智慧层 LoRA
├── stage2-persona/            说话层 LoRA
└── stage3-extra/              同人层 LoRA
```

### 只想训官方版

```bash
bash train/run.sh --official-only
```

跳过同人层，约 50 分钟。

## 六、常见问题

### 1. `error: externally-managed-environment`

Ubuntu 24.04 的 PEP 668 保护。**脚本已经自动处理**了（加 `--break-system-packages`）。

如果还是报这个错，说明检测没生效，手动加：

```bash
pip install --break-system-packages -e ".[torch,metrics,bitsandbytes]"
```

或者用 venv（更干净）：

```bash
python3 -m venv /workspace/venv
source /workspace/venv/bin/activate
bash train/run.sh
```

### 2. `没有可用的 CUDA` / `CUDA 不可用`

```bash
# 先看驱动
nvidia-smi

# 能跑但 torch 认不到，说明装的是 CPU 版 torch
pip install --force-reinstall torch --index-url https://download.pytorch.org/whl/cu121
```

CUDA 版本按 `nvidia-smi` 右上角显示的来，11.8 就用 `cu118`。

### 3. `缺少 git` / `缺少 unzip`

```bash
apt install -y git unzip
```

### 4. 依赖安装很慢 / 超时

换国内源：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 5. 显存不足（OOM）

改两个 yaml 里的 batch 设置：

```yaml
per_device_train_batch_size: 2       # 原来是 4
gradient_accumulation_steps: 8       # 原来是 4
```

等效 batch 不变，只是慢一点。

### 6. `缺少 persona.jsonl`

解压不完整。检查：

```bash
ls data/
# 应该有 7 个文件：dataset_info.json + 6 个 jsonl
```

缺了就重新解压。

### 7. 训练完模型说话很生硬

看 loss 曲线：

```bash
ls output/stage2-persona/training_loss.png
```

如果 loss 降到 0.5 以下，是过拟合了——把 `num_train_epochs` 从 3 改成 2。

## 七、跑完之后

### ⚠️ 立刻关机

挂一晚上 **20–30 元**，比训练本身贵得多。

```bash
# 确认产物都在
ls -lh /workspace/output/

# 然后关机
shutdown -h now
```

### 把模型下载回本地

```powershell
# 在你自己的电脑上
scp -r root@服务器IP:/workspace/output/amiya-official-merged "F:\models\"
```

### 本地用 Ollama 跑

```bash
# 先转 GGUF（如果 run.sh 没自动转）
python3 llama.cpp/convert_hf_to_gguf.py /workspace/output/amiya-official-merged \
  --outfile amiya-f16.gguf --outtype f16

# 量化
llama-quantize amiya-f16.gguf amiya-Q4_K_M.gguf Q4_K_M
```

写 Modelfile：

```
FROM ./amiya-Q4_K_M.gguf
PARAMETER temperature 0.85
PARAMETER top_p 0.9
PARAMETER repeat_penalty 1.1
SYSTEM """你是阿米娅，11岁，卡特斯，罗德岛的公开领袖。叫对方「博士」，用「您」。"""
```

```bash
ollama create amiya -f Modelfile
ollama run amiya "今天好累啊"
```

### 接进机器人

改 `.env`：

```ini
LLM_PROVIDER=local
DEEPSEEK_BASE_URL=http://127.0.0.1:11434/v1
DEEPSEEK_API_KEY=ollama
DEEPSEEK_MODEL=amiya
```

> ⚠️ 机器人代码里还有 4 处会挡路（强制要 key、超时 90 秒、JSON 模式、模型名映射），
> **这部分还没改**。要用的时候告诉我。
