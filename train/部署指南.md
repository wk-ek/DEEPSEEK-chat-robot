# 部署运行指南（并行智算云 · 容器云）

> 按并行智算云的容器云产品写。全部命令可直接复制粘贴。

---

## 零、概览：四步

```
① 创建容器实例（选 PyTorch 镜像）  约 1 分钟
② 登录终端（WebSSH 最简单）        即时
③ 传训练包（平台自带文件传输）      约 1 分钟
④ 跑训练                           约 1 小时
```

花费：**约 2 元**（1.88 元/卡/时 × 1 小时，存储和网络免费）

## 一、创建容器实例

登录 [控制台](https://ai.paratera.com) → 顶栏【容器云】→【容器实例】→【创建容器】

### 怎么选

| 选项 | 选什么 | 说明 |
| --- | --- | --- |
| **计费模式** | **按量计费** | 后付费，用完随时释放。别选包年包月 |
| **站点** | 有 RTX 4090 的站点 | 选完站点才能看到可用规格 |
| **资源类型** | **RTX 4090** | 默认是 3090（1.58 元/时），4090 是 1.88 元/时但快很多 |
| **资源配置** | **1 卡** | 4B 模型单卡够用。灰色=售罄，换站点 |
| **镜像类型** | **公共镜像** | |
| **开发环境** | **PyTorch 2.x + CUDA 11.8 或更高** | ⚠️ 关键，见下 |
| 容器名称 | 随便，比如 `amiya-train` | |

### ⚠️ 开发环境必须选对

平台文档明确写了：

> **RTX 4090 系列需要 CUDA 11.8 以上**

所以开发环境选 **PyTorch 2.x + CUDA 11.8 / 12.x** 的任何一个。**别选 CPU 版**，否则训练慢 100 倍。

> 万一选错了，后面可以重装：
> ```bash
> pip install torch --index-url https://download.pytorch.org/whl/cu121
> ```

### 创建

勾选协议 → 点【立即创建】→ 等 10–30 秒 → 状态变为「**运行中**」就可以了。

## 二、登录终端

平台有两种方式，**推荐 WebSSH**（不用配密钥）。

### 方式 A：WebSSH（最简单）

实例卡片 → 鼠标移到右下角【⋯】按钮 → 下拉菜单里点【**SSH 连接**】

浏览器里会直接打开一个终端页面，**可以直接敲命令**。

### 方式 B：本地 SSH（想用本地终端时）

1. 实例卡片 →【⋯】→【**查看详情**】→ 记下 **IP / 用户名 / 密码**（端口默认 22）
2. 本地打开 PowerShell：

```powershell
ssh 用户名@IP地址
# 提示输密码，粘贴进去（不会显示，输完直接回车）
```

## 三、传训练包

先把包传上去。**包在你本地这个位置**：

```
F:\qq-deepseek-robot\dist\amiya-train-20261023.zip     （约 16 MB）
```

### 方式 A：平台自带的文件传输（推荐）

1. 实例卡片 →【⋯】→【**文件传输**】
2. 平台会检测有没有装传输工具，没有就提示下载安装
3. 装好后点【文件传输】→ 确定 → 会打开连接
4. 把 zip 拖进 `/root/` 或 `/workspace/` 目录

### 方式 B：用 Xftp / WinSCP

1. 从【查看详情】拿到 IP、用户名、密码、端口（22）
2. 打开 Xftp（Ubuntu 用）或 WinSCP（Windows 用）
3. 新建会话填进去，连接
4. 左边是你电脑，右边是服务器，把 zip 拖到 `/root/`

### 方式 C：命令行 scp（如果你本地有 ssh）

在**本地** PowerShell 里：

```powershell
scp "F:\qq-deepseek-robot\dist\amiya-train-20261023.zip" 用户名@IP:/root/
```

## 四、跑训练

### 1. 解压

在容器的终端里（WebSSH 或 ssh 登录后）：

```bash
cd /root
unzip amiya-train-20261023.zip
cd amiya-train
```

> 如果提示 `unzip: command not found`：
> ```bash
> apt update && apt install -y unzip
> ```

### 2. 预检（30 秒，必做）

```bash
bash train/run.sh --dry
```

正常输出：

```
═══ 阿米娅人格模型 ═══

▸ 检查环境
  Python 3.10
  GPU: NVIDIA GeForce RTX 4090  24.0 GB
  CUDA: 12.1
✓ 环境正常

▸ 检查数据
  wisdom.jsonl  2045 条
  persona.jsonl  4824 条
  extra.jsonl  59 条
✓ 数据检查通过
```

看到 `✓ 数据检查通过` 就可以正式开训了。

### 3. 开训

```bash
bash train/run.sh
```

**就这一条。** 它会自动：

1. 检查环境
2. 装 LLaMA-Factory（首次 3–5 分钟）
3. **Stage 1** 智慧层 2045 条 —— 让她认识泰拉世界（20–30 分钟）
4. **Stage 2** 说话层 4824 条 —— 学阿米娅的语气（20–30 分钟）
5. **Stage 3** 同人层 59 条 —— 加一点味道（约 5 分钟）
6. 合并导出两个模型（约 10 分钟）

### 4. 防断线（重要）

训练要 1 小时，**WebSSH 页面断开训练就中断了**。用 `tmux` 或 `nohup`：

```bash
# 方式 A：tmux（推荐，断开还能接回去）
tmux new -s train
bash train/run.sh
# 断开：按 Ctrl+B 然后按 D
# 重新连上：tmux attach -t train

# 方式 B：nohup（后台跑，日志写文件）
nohup bash train/run.sh > train.log 2>&1 &
tail -f train.log
```

> 平台文档里也有「终端复用」的说明，讲的就是 tmux。

```powershell
scp -r 用户名@IP:/root/amiya-train/output/amiya-official-merged "F:\models\"
```

或者用平台的文件传输工具，把 `output/amiya-official-merged` 整个目录拖下来。

**下载完再关机**：

```
实例卡片 →【⋯】→【关闭容器实例】
```

> 平台文档提醒：「避免由于未完成关机产生计费」——关机要等它真的关完。

## 七、常见问题

### 1. `externally-managed-environment`

Ubuntu 24.04 的 PEP 668 保护。**脚本已经自动处理**（加 `--break-system-packages`）。

如果还是报，手动：

```bash
pip install --break-system-packages -e ".[torch,metrics,bitsandbytes]"
```

### 2. `CUDA 不可用`

先确认：

```bash
nvidia-smi           # 能输出显卡信息吗
python3 -c "import torch; print(torch.version.cuda)"
```

如果 `nvidia-smi` 正常但 torch 说没有 CUDA，说明装的是 CPU 版 torch：

```bash
# 4090 需要 CUDA 11.8+，装 12.1 最稳
pip install --force-reinstall torch --index-url https://download.pytorch.org/whl/cu121
```

### 3. 依赖装得很慢

平台推荐用北外源：

```bash
pip config set global.index-url https://mirrors.bfsu.edu.cn/pypi/web/simple
pip config set global.trusted-host mirrors.bfsu.edu.cn
```

或者清华源：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. 显存不足（OOM）

改两个 yaml：

```yaml
per_device_train_batch_size: 2       # 4 → 2
gradient_accumulation_steps: 8       # 4 → 8
```

等效 batch 不变，只是慢一点。4090 24G 跑 4B QLoRA 理论上不会 OOM，真遇到了先看是不是选了多卡但没配好。

### 5. `unzip: command not found`

```bash
apt update && apt install -y unzip
```

### 6. 训练中断了

先看日志：

```bash
tail -50 train.log     # 如果用 nohup
# 或者直接看终端的输出
```

重跑会从头开始（LoRA 没有断点续传）。如果要保留进度，改 yaml 里的 `save_steps` 调小（比如 50），中断后可以用 `--resume_from_checkpoint` 续训。

### 7. 模型说话很生硬

看 loss 曲线：

```bash
ls output/stage2-persona/training_loss.png
```

下载下来看。如果 loss 降到 0.5 以下，是**过拟合**了——把 `num_train_epochs` 从 3 改成 2 重训。

```bash
# ① 控制台创建容器：RTX 4090 / 1卡 / 公共镜像 / PyTorch 2.x + CUDA 11.8+
# ② WebSSH 登录
# ③ 文件传输把 zip 传到 /root/
# ④ 终端里：
cd /root && unzip amiya-train-20261023.zip && cd amiya-train
tmux new -s train
bash train/run.sh --dry    # 先预检
bash train/run.sh          # 正式训练
# ⑤ 训完 scp 下载模型，再关机
```
